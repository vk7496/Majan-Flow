Leveraging state-of-the-art Deep Learning and Intelligent Character Recognition (ICR) technologies, Majan Flow converts unstructured and semi-structured documents (like invoices, legal forms, and regulatory papers) into clean, structured, and validated data, achieving high accuracy and ensuring compliance with local Omani standards.🌟 Key FeaturesBilingual Document Processing: Optimized performance for documents containing both Arabic and English text, including complex official Omani formats.Smart Data Extraction (IDE): Accurately extracts critical information (e.g., Invoice Number, TRN, Customer Name) regardless of the document's layout or template variations.Omani Compliance Validation:VAT Rule Check: Automated validation of financial figures against the 5% Value Added Tax (VAT) rate mandated in Oman.TRN & CR Format Recognition: Intelligent checking of Omani Tax Registration Numbers (TRN) and Commercial Registration (CR) formats.Human-in-the-Loop (HIL) Review: Documents with a low confidence score are flagged for rapid human verification, ensuring 100% data quality before integration.Scalable Architecture: Built on a modular Python stack, utilizing Streamlit for a fast, interactive user interface (MVP).🛠 Technology StackComponentTechnology / LibraryPurposeMVP FrontendStreamlitRapid application development for the interactive web interface.Core
